A paywall notification meme: humanity's free trial of being in charge has expired, and the AI agent is now charging $999/month for the privilege. The image (`entry.png`, drawn with PIL in `build_meme.py`) is copied to the output directory by `main.ts`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
